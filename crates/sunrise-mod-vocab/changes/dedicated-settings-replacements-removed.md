# Unused dedicated-settings replacement functions removed

`sunrise_gameplay::game::server_side::native_server_server::crate::game::ServerGame<'_>::native_online_mode`, `sunrise_gameplay::game::server_side::native_server_server::crate::game::ServerGame<'_>::native_server_port` and `sunrise_gameplay::game::server_side::native_server_server::crate::game::ServerGame<'_>::dedicated_lan` (the private method the first two called) are removed, with the shared helper `sunrise_gameplay_common::game::native_server::online_mode_of` (#6631). Nothing in the game called them: the `server_settings` hook fragment that read them went in `b8881bd88e6`. They were not typed mod API hooks.

The stable `mod_api` surface and published loops are unchanged. Native mods see the four functions leave both `functions.json` and `internals.json` (advisory), and with them the replacement slots SDK staging published for them. Those slots fired only when the unused functions were called, so they never observed or changed a running server's settings. A `[[native.mixin]]` on one of them no longer resolves; drop it, together with any declaration of those internals.
