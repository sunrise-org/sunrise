# Q-055: How many folders the guide path takes in the `guides/` layout

**Spec section:** 2.1.2 (and 2.1.1, 2.1.5).

**Question.** Pages of guide `<gns>:<gpath>` are the `.md` files under `guides/<gns>/<gpath>/`. When Sunrise finds
the guides from the files alone (2.3.1), a file `assets/x/guides/mod/guide/sub/page.md` could belong to guide
`mod:guide` (page `sub/page.md`) or to guide `mod:guide/sub` (page `page.md`). Does a guide path ever have more than
one folder?

**What was observed.** The spec's examples (`mod:guide`, `mymod:guide`) and the definition file's location
(`guideme_guides/<name>.json`, one name) all use one folder. Nothing in the spec shows a path with a `/`.

**Implementer's decision:** see `guides-decisions.md`, Q-055.
